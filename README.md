# AnkiGenerator

Aplicação simples para geração de cartões com áudio usando o GPT para o Anki com base em palavras e frases em inglês

## Getting Started

Instale as dependências

```bash
npm i
```

Crie uma cópia do arquivo .env.example para .env e preencha as variáveis de ambiente

Execute o servidor de desenvolvimento

```bash
npm dev
```

Acesse http://localhost:3000/phrases e gere suas frases :)
